# **EcoCity - Aplicación de Reporte de Incidencias Urbanas 🌆**

## JESÚS MACÍAS / CARLOS SÁNCHEZ

**EcoCity** es una aplicación móvil diseñada para facilitar el reporte y seguimiento de incidencias urbanas, como baches, farolas rotas, basuras y más. El objetivo principal de la aplicación es proporcionar a los usuarios una forma fácil y rápida de reportar problemas en su ciudad y darles seguimiento en tiempo real.

## **Objetivo del Proyecto 🎯**

El objetivo de este proyecto es diseñar, prototipar, evaluar y mejorar la interfaz gráfica de **EcoCity**, aplicando principios de **Material Design**, usabilidad, accesibilidad y diseño centrado en el usuario. Este proyecto se ha realizado usando **Figma** para el prototipado y **Canva** para la presentación final.

## **Características Principales 🛠️**

1. **Pantalla de Login 🔑**: 
   - Permite a los usuarios iniciar sesión con su correo y contraseña.
   - Validaciones visuales de errores y mensajes de confirmación.

2. **Pantalla Principal – Listado de Incidencias 📋**:
   - Muestra el listado de incidencias cercanas, con filtros por urgencia.
   - Opción para crear nuevas incidencias.

3. **Pantalla de Creación/Edición de Incidencia ✏️**:
   - Formulario para agregar una nueva incidencia con campos como título, descripción, urgencia, ubicación y multimedia (imágenes y audio).

4. **Pantalla de Detalle de Incidencia 🔍**:
   - Muestra información detallada sobre cada incidencia.
   - Permite ver el estado de la incidencia y tomar acciones secundarias como editar o eliminar.

5. **Pantalla de Chat de Soporte 💬**:
   - Permite a los usuarios comunicarse con el soporte para resolver problemas relacionados con las incidencias reportadas.

## **Tecnologías Utilizadas 💻**

- **Figma**: Herramienta de diseño y prototipado de interfaces.
- **Canva**: Herramienta para crear presentaciones visuales.
- **GitHub**: Plataforma para la gestión del proyecto y el control de versiones.

## **Proceso de Diseño 🎨**

1. **Prototipado en Figma**:
   - Se creó un prototipo navegable con todas las pantallas necesarias, usando componentes y auto-layout para asegurar la coherencia visual.
   - Se aplicaron los principios de **Material Design**, como una paleta de colores coherente, tipografía adecuada, iconografía material y una jerarquía visual clara.

2. **Pruebas de Usabilidad y Accesibilidad 👥**:
   - Se realizaron pruebas con al menos 5 usuarios para evaluar la usabilidad de la app.
   - Se recogieron datos sobre el tiempo de respuesta, errores cometidos y la satisfacción de los usuarios (valoración de 1 a 5).
   - Las pruebas identificaron áreas de mejora, como la visibilidad de botones y la facilidad de uso del selector de ubicación.

3. **Rediseño Basado en las Pruebas 🔄**:
   - Con los resultados de las pruebas, se implementaron cambios para mejorar la experiencia del usuario, como ajustes en el diseño de botones y la mejora de la visibilidad de los elementos clave.

## **Futuras Mejoras 🚀**

- **Mejorar la función de ubicación 📍**: Implementar un sistema más preciso para seleccionar la ubicación de las incidencias en el mapa.
- **Añadir notificaciones push 🔔**: Para notificar a los usuarios sobre el estado de sus incidencias en tiempo real.
- **Optimizar la velocidad ⚡**: Mejorar el tiempo de carga de las pantallas y la fluidez general de la app.
- **Agregar más interacciones 💡**: Como permitir que los usuarios comenten o añadan fotos a incidencias ya reportadas.
